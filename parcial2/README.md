## Requisitos

- Python 3.8 o superior
- No requiere librerías externas (solo la biblioteca estándar)

## Estructura

```
parcial2/
├── main.py           # Menú principal
├── hacer_sencillo.py # Problema 1 — Cambio de monedas (Greedy)
├── knapsack.py       # Problema 2 — Knapsack fraccionado (Greedy)
└── nokia.py          # Problema 3 — Nokia combinaciones (DP)
```

## Cómo ejecutar

### Mac / Linux

```bash
python3 main.py
```

### Windows

```cmd
python main.py
```

## Uso

Al ejecutar `main.py` aparece un menú interactivo:

```
1 → Hacer Sencillo (cambio de monedas)
2 → Knapsack Fraccionado
3 → Nokia 3230 Combinaciones
4 → Todos
0 → Salir
```

Cada algoritmo muestra 3 casos de prueba no triviales con la traza paso a paso.  
También puedes ejecutar cada módulo por separado:

```bash
python3 hacer_sencillo.py
python3 knapsack.py
python3 nokia.py
```
